# Проверочный лист безопасности для бизнес-систем PropDevelopment

## Обоснование выбора разделов

На основе анализа описания системы PropDevelopment и выявленных проблем компании, для проверочного листа выбраны следующие приоритетные разделы:

### 1. **Безопасность данных** (критический приоритет)
**Обоснование:** Это первая глобальная проблема компании. Выявлены:
- Нарушение контроля данных (несколько точек регистрации клиентов без координации)
- Отсутствие системного контроля за передаваемыми данными между IT-продуктами и через API партнёров
- Отсутствие единых политик безопасности при интеграциях (контроль передаваемых данных)
- Отсутствие ограничений на доступ к данным со стороны систем обработки данных
- Проблема управления и хранения потоков данных блокирует реализацию новых продуктов

### 2. **Управление доступом** (критический приоритет)
**Обоснование:** Это вторая глобальная проблема компании (проблемы с API партнёров). Выявлены критические проблемы контроля доступа:
- Отображение данных одного клиента другому клиенту в личном кабинете (нарушение разграничения доступа)
- Партнёры могут видеть и изменять данные клиентов других управляющих компаний (нарушение принципа минимальных привилегий)
- Необходимость контроля доступа к персональным данным

### 3. **Защита инфраструктуры** (высокий приоритет)
**Обоснование:**
- Гибридная инфраструктура (собственные серверы + облако) требует особого внимания
- Доступ внешних пользователей через firewall требует проверки настроек
- Необходимость защиты от инцидентов (как у конкурента)

### 4. **Управление инцидентами** (высокий приоритет)
**Обоснование:**
- Недавняя утечка данных у конкурента
- Необходимость предотвращения подобных инцидентов
- Отсутствие упоминания о системах мониторинга безопасности

### 5. **Специфические аспекты** (средний приоритет)
**Обоснование:**
- Наличие мобильного приложения для собственников
- Интеграции с внешними системами (госорганы, управляющие компании)
- Необходимость соответствия законодательству РФ

## Идентифицированные системы и их характеристики безопасности

### Домен "Продажи":
1. **Витрина продаж** (монолит) - публичный доступ, высокий риск
2. **client-tour-app** - обработка данных клиентов, средний риск
3. **client-mart-app** - онлайн-сделки, интеграция с госорганами, критический риск
4. **client-crm-app** - хранение персональных данных, критический риск
5. **client-mart-estate-app** - данные о недвижимости, средний риск

### Домен "ЖКУ":
1. **Витрина** - публичный доступ для собственников
2. **tenant-core-app** - предоставление услуг, интеграция с партнёрами, высокий риск
3. **CRM собственников** - персональные данные, критический риск

### Домен "Финансы":
1. **accountant-service-1** - финансовый учёт, критический риск
2. **Служба каталогов** - централизованное управление, критический риск

### Домен "Дата":
1. **Хранилище данных** - агрегация всех данных, критический риск
2. **BI** - аналитика, средний риск
3. **Отчётность** - может содержать персональные данные, средний риск

### Мобильное приложение:
- Управление "Умным домом", оплата ЖКХ - высокий риск
